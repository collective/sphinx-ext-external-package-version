.. module:: collective.sphinxextexternalpackageversion
   :synopsis: Sphinx extension to show the version of an external package through a special syntax in the documentation.

To get the latest stable version of a GitHub repository that is in a release on GitHub, place ``{{ version x/y }}`` in your documentation, where ``x/y`` is the title of the GitHub repository, ``x`` is the owner, ``y`` is the actual repository name. See the `README.rst`_ for more details.
